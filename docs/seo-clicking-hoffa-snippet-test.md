# Clicking and Hoffa snippet test

Prepared September 8, 2026. Production release date: pending approval and
verified deployment. This is a separate two-page test after PR #54.

Only `metaTitle` and `metaDescription` change in these two articles:

- `knee-clicking-when-walking`: retain walking and bending, add the existing
  squatting topic, and use a natural question. The body still contains stairs
  and straightening sections. The description distinguishes clicking with and
  without pain without promising a diagnosis.
- `hoffa-fat-pad-impingement`: keep the specific impingement topic and explain
  the term in plain language. The description reflects the existing anatomy,
  symptom, MRI and treatment discussion, not a new medical claim.

H1s, article bodies, intros, Quick Answers, sources, dates, URLs, images,
guide cards, CTAs and analytics remain unchanged. This is not an article
rewrite, consolidation, or a claim that query cannibalization has been ruled
out. It does not change the three guides in PR #54 or the stairs candidates.

The September 7 Bing page export shows 4,191 impressions/80 clicks for clicking
and 595/4 for Hoffa. Its date range is not supplied. The separate keyword export
has no query-to-page mapping, so it cannot establish page-specific attribution.
No fresh page-filtered GSC/Bing query extraction was performed for this change.
The approved copy is supported by the existing article coverage; a ranking or
CTR gain is a hypothesis, not a forecast.

Record the actual production release date. Review after 2-3 weeks, then use
equivalent 28-day periods when sufficient data exists. Compare Google and Bing
separately, considering page/query, available country/device filters, position,
impression volume and query mix. Avoid further copy/body changes during that
